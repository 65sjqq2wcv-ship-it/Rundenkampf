1. Überblick

Rundenkampfbericht ist eine Progressive Web App zur digitalen Verwaltung und Auswertung von Schießsport-Rundenkämpfen. Die Anwendung ermöglicht die einfache Erfassung von Schussergebnissen, die automatische Berechnung von Mannschaftsergebnissen und den Export von Berichten.

✨ Hauptmerkmale:
  • ✅ Zwei verschiedene Wettkampfmodi (Präzision/Duell oder Annex Scheibe)
  • ✅ Unterstützung für Mannschaften und Einzelschützen
  • ✅ Automatische Wertungsberechnung (beste 3 von 4 Schützen)
  • ✅ Scheibendokumentation mit Kamera
  • ✅ PDF-Export für Berichte
  • ✅ Offline-Funktionalität (PWA)
  • ✅ Vollständige Datensicherung lokal im Browser

Wettkampfmodi

🎯 Präzision/Duell

Dieser Modus ist für klassische Schießwettkämpfe mit zwei Phasen:

  • Präzision: 20 Schuss, Wertung 0-10 Ringe
  • Duell: 20 Schuss, Wertung 0-10 Ringe
  • Gesamtergebnis: Summe beider Phasen (max. 400 Punkte)

🎪 Annex Scheibe

Dieser Modus ermöglicht die Erfassung von mehreren Serien:

  • Serien: 5 Serien à 8 Schuss
  • Wertung pro Schuss: 0-3 Punkte
  • Gesamtergebnis: Summe aller 40 Schüsse (max. 120 Punkte)

2. Installation & Erste Schritte

PWA Installation (empfohlen)

Die Anwendung kann wie eine native App auf dem Gerät installiert werden:

  1. Website öffnen: Rundenkampfbericht im Browser laden
  2. Installieren:
    • iOS: Teilen-Button → "Zum Home-Bildschirm"
    • Android: Menü → "Zur Startseite hinzufügen"
    • Desktop: Adressleisten-Button oder Menü → "Installieren"
  3. Offline-Nutzung: Die App funktioniert auch ohne Internetverbindung

Browser-Anforderungen

Anforderung Details
Browser Chrome, Firefox, Safari, Edge (neueste Versionen)
Speicher ~50 MB LocalStorage verfügbar
Verbindung Beim ersten Start notwendig, dann offline möglich
Kamera (optional) Für Scheibendokumentation (HTTPS oder localhost erforderlich)
⚠️ Wichtig: Alle Daten werden ausschließlich lokal im Browser gespeichert. Bei Löschen von Browser-Daten gehen alle Einträge verloren! Nutzen Sie regelmäßig die Sicherungsfunktion in den Einstellungen.

3. Benutzeroberfläche

Navigationsleiste

Oben auf jedem Bildschirm befindet sich eine Navigationsleiste mit folgenden Optionen:

Symbol Funktion Beschreibung
📊 Übersicht Zeigt alle Mannschaften und aktuelle Ergebnisse
✏️ Erfassen Erfassung neuer Schussergebnisse
👥 Teams Verwaltung von Mannschaften und Schützen
⚙️ Einstellungen Konfiguration der Anwendung

Filterfunktion

In der Übersicht können Sie mit dem Filtere-Button 🔍 die angezeigten Mannschaften eingrenzen. Dies ist besonders bei vielen Teams hilfreich.

4. Mannschaften & Schützen verwalten

Neue Mannschaft hinzufügen

  1. Navigieren Sie zur Teams-Seite
  2. Klicken Sie auf ➕ Team hinzufügen
  3. Füllen Sie folgende Felder aus:
    • Mannschaftsname: z.B. "Schützenverein ABC"
    • Mannschaftsführer Name, E-Mail, Telefon
  4. Der Mannschaftsführer wird automatisch als erster Schütze hinzugefügt
  5. Sie können weitere Schützen mit Schütze hinzufügen (n/4) ergänzen
  6. Speichern Sie die Mannschaft mit Speichern
💡 Tipp: Eine Mannschaft kann zwischen 1-4 Schützen haben. Bei der Wertung werden die besten 3 Ergebnisse verwendet (wenn 4 Schützen vorhanden sind).

Einzelschützen hinzufügen

Einzelschützen sind Sportler, die nicht in einer Mannschaft starten:

  1. Klicken Sie auf 👤 Einzelschütze hinzufügen
  2. Geben Sie den Namen des Schützen ein
  3. Speichern Sie den Eintrag

CSV-Import

Sie können Mannschaften und Schützen per CSV-Datei importieren. Das Format muss sein:

Name; Verein; Einzelschütze
Max Mustermann; Schützenverein ABC; nein
Erika Musterfrau; ; ja

  • Name: Name des Schützen
  • Verein: Name der Mannschaft (leer = Einzelschütze)
  • Einzelschütze: "ja" oder "nein"

5. Ergebnisse erfassen

Schussergebnisse eingeben

  1. Navigieren Sie zur Erfassen-Seite
  2. Wählen Sie die Mannschaft aus
  3. Wählen Sie den Schützen aus
  4. Im Modus "Präzision/Duell":
    • Wählen Sie die Phase (Präzision oder Duell)
    • Wählen Sie die Schussnummer (1-20)
    • Geben Sie die Ringzahl ein (0-10)
  5. Im Modus "Annex Scheibe":
    • Wählen Sie die Serie (1-5)
    • Wählen Sie die Schussnummer (1-8)
    • Geben Sie die Punktzahl ein (0-3)
  6. Das Ergebnis wird automatisch gespeichert

Scheibendokumentation

Sie können Schießscheiben fotografieren und automatisch mit Informationen beschriften:

  1. Klicken Sie auf 📷 Kamera im Erfassungsbereich
  2. Fotografieren Sie die Schießscheibe
  3. Das Foto wird automatisch mit folgendem Info-Overlay versehen:
    • Mannschaftsname
    • Schützenname
    • Datum und Uhrzeit
  4. Das Bild wird automatisch heruntergeladen
⚠️ Wichtig: Die Kamera funktioniert nur über HTTPS oder localhost. Kamerazugriff erfordert Browser-Berechtigung.

Daten korrigieren

Um bereits eingegebene Ergebnisse zu korrigieren:

  1. Wählen Sie erneut denselben Schützen und Schuss
  2. Geben Sie den neuen Wert ein (überschreibt den alten)

6. Übersicht & PDF-Reports

Übersichtsseite

Die Übersicht zeigt:

  • ✅ Aktuelle Disziplin und Wettkampfmodus
  • ✅ Aktueller Wettkampfort (aus den Einstellungen)
  • ✅ Alle Mannschaften mit detaillierten Schützen-Ergebnissen
  • ✅ Einzelschützen-Ergebnisse
  • ✅ Begegnungen zwischen Mannschaften
  • ✅ Kontaktdaten des Rundenkampfleiters und Mannschaftsführer

PDF-Export

Sie können die gesamte Übersicht als PDF-Datei exportieren:

  1. Gehen Sie zur Übersicht-Seite
  2. Klicken Sie auf 📄 PDF
  3. Die PDF wird automatisch erzeugt und heruntergeladen
  4. Der PDF enthält alle Ergebnisse in druckoptimierter Form
📋 Inhalte des PDF-Reports:
  • Wettkampfinformationen
  • Vollständige Ergebnistabellen aller Mannschaften
  • Einzelschützen-Ergebnisse
  • Mannschaftsbewertungen
  • Kontaktdaten

7. Einstellungen

Wettkampfkonfiguration

In den Einstellungen können Sie folgende Parameter anpassen:

Wettbewerbsmodus

  • Wählen Sie zwischen "Präzision/Duell" oder "Annex Scheibe"
  • Diese Einstellung gilt für alle erfassten Daten

Aktuelle Disziplin

  • Wählen Sie die Waffenart (z.B. "Pistole 10m", "Gewehr 50m")
  • Erstellen Sie neue Disziplinen nach Bedarf

Aktueller Wettkampfort

  • Geben Sie den Ort des Wettkampfs ein
  • Dieser wird in der Übersicht angezeigt und in Reports enthalten

Vereinseinstellungen

Vereinsname

Geben Sie den Namen Ihres Schützenvereins ein (wird für interne Verwaltung genutzt)

Vereinslogo

Sie können ein Logo-Bild hochladen (JPG, PNG, GIF, max. 5 MB). Dieses wird ggf. in Reports angezeigt.

Rundenkampfleiter

Erfassen Sie die Kontaktdaten des Wettkampfleiters:

  • Name
  • E-Mail
  • Telefon
💡 Tipp: Diese Daten werden in der Übersicht und in PDF-Reports angezeigt.

Foto-Overlay Einstellungen

Für die Scheibendokumentation können Sie anpassen:

  • Overlay-Größe: Vergrößert/verkleinert die Informationen auf dem Foto
  • Transparenz: Einstellen wie durchsichtig das Overlay sein soll

Label-Einstellungen

Für den Etikettendruck können Sie folgende Parameter konfigurieren:

  • Etikett-Abmessungen (Breite, Höhe in mm)
  • Seitenränder
  • Anzahl der Spalten und Zeilen
  • Abstand zwischen Etiketten
  • Anzahl der Kopien

Sicherung & Wiederherstellung

Wichtig: Erstellen Sie regelmäßig Sicherungen!

Backup erstellen

  1. Klicken Sie auf 💾 Backup erstellen
  2. Eine JSON-Datei mit allen Daten wird heruntergeladen
  3. Speichern Sie die Datei sicher

Backup wiederherstellen

  1. Klicken Sie auf 📥 Wiederherstellen
  2. Wählen Sie eine zuvor erstellte Backup-Datei
  3. Alle Daten werden wiederhergestellt
⚠️ Achtung: Die Wiederherstellung überschreibt alle aktuellen Daten! Erstellen Sie vor dem Import ein aktuelles Backup.

8. FAQ & Tipps

Häufig gestellte Fragen

❓ Meine Daten sind weg - wie stelle ich sie wieder her?

Antwort: Falls Sie ein Backup erstellt haben, können Sie dieses in den Einstellungen unter "Sicherung & Wiederherstellung" wiederherstellen. Ansonsten sind die Daten leider verloren, da alles lokal im Browser gespeichert wird.

❓ Kann ich die App auf mehreren Geräten nutzen?

Antwort: Ja! Erstellen Sie auf Gerät A ein Backup und importieren Sie es auf Gerät B. So haben Sie auf beiden Geräten dieselben Daten.

❓ Wie funktioniert die Offline-Nutzung?

Antwort: Nach der ersten vollständigen Nutzung werden alle wichtigen Daten im Browser gespeichert. Sie können die App dann ohne Internetverbindung verwenden. Die Synchronisierung findet statt, wenn Sie die App wieder online öffnen.

❓ Warum zeigt die Übersicht unterschiedliche Mannschaften als die Erfassungsseite?

Antwort: Das bedeutet, dass Sie den Filter aktiviert haben. Klicken Sie auf das Filtere-Symbol 🔍 um alle Mannschaften anzuzeigen.

❓ Wie ändere ich den Wettkampfmodus, wenn ich bereits Ergebnisse erfasst habe?

Antwort: Gehen Sie zu Einstellungen und ändern Sie den Modus. Warnung: Dies kann zu Dateninkonsistenzen führen. Erstellen Sie vorher ein Backup!

❓ Kann ich Schützen aus der Mannschaft löschen?

Antwort: Ja, in der Bearbeitung der Mannschaft können Sie einzelne Schützen mit dem "Löschen"-Button entfernen. Die bereits erfassten Ergebnisse bleiben erhalten.

Praktische Tipps

💡 Tipp 1: Datenbestand sichern
Erstellen Sie täglich ein Backup! Gehen Sie zu Einstellungen → Sicherung & Wiederherstellung → Backup erstellen.
💡 Tipp 2: Filter nutzen
Bei vielen Teams nutzen Sie den Filter in der Übersicht, um schnell die relevanten Teams zu finden.
💡 Tipp 3: Schnelle Erfassung
Speichern Sie lange Listen von Wettkampfergebnissen, indem Sie bei gleicher Person von Schuss zu Schuss wechseln - die Auswahl bleibt erhalten.
💡 Tipp 4: PDF-Reports drucken
Nutzen Sie den PDF-Export für offizielle Auswertungsberichte. Diese können dann ausgedruckt oder elektronisch weitergeleitet werden.
💡 Tipp 5: Kamera kalibrieren
Testen Sie die Scheibendokumentation mit verschiedenen Overlay-Größen und Transparenz-Einstellungen, um die optimale Lesbarkeit zu erreichen.
💡 Tipp 6: Etikett-Vorschau
Drucken Sie zunächst ein Test-Etikett auf normalem Papier, bevor Sie auf die Etiketten-Blanko-Bögen drucken.

Troubleshooting

🔧 Problem: Kamera funktioniert nicht

Lösung:

  • Überprüfen Sie, ob HTTPS aktiviert ist (außer localhost)
  • Erlauben Sie der App Kamerazugriff in den Browser-Einstellungen
  • Versuchen Sie es in einem anderen Browser

🔧 Problem: App lädt sehr langsam

Lösung:

  • Löschen Sie den Browser-Cache
  • Deinstallieren Sie die PWA und installieren Sie neu
  • Überprüfen Sie Ihre Internetverbindung

🔧 Problem: Speichern funktioniert nicht

Lösung:

  • Überprüfen Sie, ob LocalStorage aktiviert ist
  • Leeren Sie den Browser-Cache und Cookies
  • Nutzen Sie einen anderen Browser
  • Überprüfen Sie verfügbaren Festplattenspeicher
